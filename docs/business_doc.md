# ZooCare — система обліку та догляду за тваринами

## Короткий опис
ZooCare — це веб-система для автоматизації процесів догляду за тваринами в зоопарку. Вона дозволяє працівникам реєструвати тварин, планувати годування, лікування, відстежувати стан здоров’я та вести історію змін.

## Ролі користувачів
- **Адміністратор** — керує доступами
- **Ветеринар** — додає медичні записи
- **Доглядальник** — оновлює щоденний стан тварин

## Сценарії використання
1. Додати нову тварину
2. Створити запис про вакцинацію
3. Призначити ролі працівникам
4. Оновити щоденний стан
5. Переглянути історію хвороб

## Функціональні вимоги
- Авторизація
- CRUD для тварин
- Медичні записи
- Ролі та доступи

## Нефункціональні вимоги
- HTTPS
- Висока доступність
- Резервне копіювання

## Обмеження
- Без мобільного додатку
- Без інтеграції з оплатами
